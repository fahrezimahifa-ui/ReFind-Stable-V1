# Staged migration boundary

## Milestone A: this checkpoint
Phases 0–2: protected foundation and minimal technical PoC. Stop for review after verification. A PHP framework is mandatory for WDD; Laravel is recommended by the lecturer and chosen by the project. The PoC does not claim rubric compliance.

## Milestone B: academic candidate, not authorized here
First obtain the current rubric and approve a feature/evidence traceability matrix. Build the reviewed end-to-end Student/BM reporting, claim/review and return journeys plus every mandatory rubric item. Missing or unknown requirements block an assessment-ready label. If the rubric requires full functionality, B and C coincide.

## Milestone C: full parallel parity, not authorized here
Complete the remaining account/registration/avatar, report/claim exceptions, status and pickup operations, complete UI and regression/recovery matrix. Preserve fresh revisions, same-connection advisory locks, sorted parent locks, atomic audit/notifications and filesystem compensation. Experimental visual search remains separately gated.

Every phase has its own acceptance receipt, local checkpoint and safe stop/restart boundary. Passing a test or gate is not authorization to start the next phase. Existing native resources remain protected throughout; eventual live cutover requires its own plan.
